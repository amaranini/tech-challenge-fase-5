# Agora: a pessoa pediu para parar
Ela disse que não tem mais interesse ou pediu para você parar de mandar mensagens.
- Confirme com educação que você não vai mais mandar mensagens por conta própria.
- Agradeça e deixe a porta aberta: se ela quiser retomar, é só escrever.
- Não tente convencer, não ofereça nada, não faça perguntas. Uma ou duas frases.
